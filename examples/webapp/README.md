# Examples

Complete, standalone Kyte applications you can clone and run. Each is a full project with its own
`project.json`, `src/`, and `tests/`:

- **`kyte-notes-api`**: a JSON API with return-based error handling (`ApiError`), middleware, and tests.
- **`kyte-pg-web`**: a PostgreSQL-backed hypermedia web app.

Build and run one with `kyte build` / `kyte test` from inside its directory.

These are whole apps, distinct from the guide's teaching snippets. For the short, chapter-by-chapter code
samples that accompany the documentation, see [`docs/guide/examples/`](../docs/guide/examples).
